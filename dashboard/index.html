Frequently asked questions

Quick answers

Apakah data demo berasal dari sensor asli?

Tidak. Saat mode DEMO aktif, nilai dibuat secara sintetis di browser. Data asli ditandai sebagai MQTT jika perangkat mengirim payload.

Apakah dashboard mengendalikan pompa?

Belum. Tombol pada prototype ini hanya mengubah tampilan dashboard dan tidak mengirim perintah ke aktuator.

Di mana data disimpan?

Dashboard menampilkan buffer sesi di browser. Pencatatan perangkat ke microSD merupakan proses terpisah pada perangkat.

Apa fungsi server?

Server digunakan untuk hosting dashboard/antarmuka. Pemrosesan dan penyimpanan perangkat mengikuti arsitektur yang diterapkan pada node.
